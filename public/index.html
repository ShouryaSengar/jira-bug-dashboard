Jira connection

This is the hosted demo. It shows sample data only and cannot reach Jira. To use your own data, run the app on your computer (). Your credentials are then saved on your machine and never sent to any server except Jira.

Create a token at id.atlassian.com. It is stored only in ~/.jira-bug-dashboard/config.json (readable by your user only) and is never shown here again.

Get the app

Free and open source (MIT). It runs on your computer, so your Jira credentials never leave it.

Open on GitHub
  1. Install Node.js 18+.
  2. Download the project, either with git or via Code → Download ZIP on GitHub: 
    git clone https://github.com/ShouryaSengar/jira-bug-dashboard.git
cd jira-bug-dashboard
  3. Install and start: 
    npm install
npm start
  4. Open http://localhost:4545 and enter your Jira URL, email and API token when asked.
  5. Type an epic key such as ABC-123 and press Track.
