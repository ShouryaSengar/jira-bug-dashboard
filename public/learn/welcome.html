Welcome: how to use these guides

Everything about how Jira Bug Dashboard works, from the button you click to the computer in a data centre that answers, written so that someone new to all of it can follow.

⏱ 4 min readGuide 1 of 47

What you will be able to do after reading

  • Explain, in your own words, how the app gets your Jira bugs onto your screen.
  • Draw the system on a whiteboard: the browser, the server, Cloudflare, Atlassian, the database.
  • Find any piece of code and know why it exists.
  • Deploy this app, and deploy a completely different app on Cloudflare, without help.
  • Reason about security, privacy and cost like an engineer who built it.

How the guides are organised

The guides are grouped into categories (left sidebar). Inside a category, sub-categories group related guides. Each guide has a reading time, a table of contents on the right, and previous / next links at the bottom, so you can read in order like a book.

Tracking your progress

At the bottom of each guide there is a Mark this guide as done button. Your progress is saved in this browser only (in localStorage, never sent anywhere) and shown in the sidebar and on the Learn home page. Press / anywhere to search the guides.

These guides describe real codeEvery claim here is about the actual source in the GitHub repository. When the code and a guide disagree, the code wins; please report it.
