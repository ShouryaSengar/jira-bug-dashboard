Run the Local edition

From nothing to a running dashboard on your computer in about ten minutes. No accounts other than your existing Jira.

⏱ 6 min readGuide 39 of 47

What you need

  • Node.js 18 or newer: download from nodejs.org. Check with node -v in a terminal.
  • Git (optional; you can download a ZIP instead). Check with git --version.
  • A Jira Cloud account (your company's …atlassian.net).

Steps

  1. Get the code. 
    git clone https://github.com/ShouryaSengar/jira-bug-dashboard.git
cd jira-bug-dashboard
    Or on GitHub: Code → Download ZIP, unzip, open a terminal in the folder.
  2. Install and start. 
    npm install
npm start
    npm install downloads TypeScript (the only dependency). npm start compiles and starts the server. You should see Jira bug dashboard: http://localhost:4545.
  3. Create an API token. Open id.atlassian.com → Security → API tokens → Create API token, name it, copy it.
  4. Connect. Open http://localhost:4545. The settings dialog opens: enter your Jira URL (for example https://yourcompany.atlassian.net), your Atlassian email and the token. Verify & save checks them against Jira before saving.
  5. Use it. Paste an epic key into Track, or open For You. Open JARVIS and press Test announcement (click the page once first, browsers require it).

Where things are saved

WhatWhere
URL, email, token~/.jira-bug-dashboard/config.json (readable only by your user)
JARVIS snapshot and history~/.jira-bug-dashboard/jarvis.json
Preferences, filters, cachesyour browser's localStorage

Nothing is stored in the project folder, so nothing secret can be committed to Git.

Useful variations

PORT=4546 npm start                                  # another port
JIRA_URL=https://x.atlassian.net JIRA_USERNAME=me@x.com JIRA_API_TOKEN=… npm start   # no saved file
npm run dev                                          # recompile and restart on every change

Updating

git pull
npm install
npm start

Stopping and removing

  • Stop: Ctrl+C in the terminal (or close it).
  • Remove credentials: Settings → Sign out, or delete ~/.jira-bug-dashboard.
  • Revoke the token at id.atlassian.com when you no longer need it.

If something goes wrong

SymptomFix
Port 4545 is in useanother copy is running; stop it, or PORT=4546 npm start
"Jira rejected the credentials"wrong email or token, or the token expired; create a new one
No severity shownSettings → Advanced → enter your site's severity field name
JARVIS silentclick the page once; check Voice is on; check the browser volume
