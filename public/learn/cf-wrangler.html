Wrangler cheat sheet

Wrangler is Cloudflare's command-line tool. These are the commands used for this app, grouped by task, with what each one does and when to use it.

⏱ 8 min readGuide 32 of 47
Running WranglerInstall it per project (npm install -D wrangler) and run it with npx wrangler … from the folder containing wrangler.jsonc (here: cloud/). Add --env production or --env dev to pick the environment. Set WRANGLER_SEND_METRICS=false to turn off usage telemetry.

Account

CommandWhat it does
npx wrangler loginOpens Cloudflare in the browser to authorise Wrangler (OAuth). Add --browser=false to print the link instead, then open it yourself in the browser you use.
npx wrangler whoamiShows the account, its id and the token's permissions
npx wrangler logoutRemoves the saved login from this computer
Login gotcha we hitIf the login link opens in one browser and you approve in another (or in an old tab), Cloudflare answers "No CSRF value available in the session cookie" and Wrangler warns "query string parameter doesn't match". Close old tabs, start a new login, and approve in the same browser that opened the link.

Local development

CommandWhat it does
npx wrangler dev --env devRuns the Worker locally (workerd) with local D1, hot reload on file changes
… --test-scheduledEnables /__scheduled?cron=… to trigger the cron handler by hand
… --port 8787 --ip 127.0.0.1Where to listen (this repo wraps it in scripts/dev-server.sh)
npx wrangler typesGenerates TypeScript types for your bindings

D1 database

CommandWhat it does
npx wrangler d1 create jbd-cloudCreates a database; prints its database_id for wrangler.jsonc
npx wrangler d1 listLists databases, sizes, table counts
npx wrangler d1 migrations apply DB --local --env devApplies new migration files to the local copy
npx wrangler d1 migrations apply DB --remote --env production…to the real database (asks for confirmation)
npx wrangler d1 migrations list DB --remote --env productionShows which migrations have run
npx wrangler d1 execute DB --remote --env production --command "SQL"Runs one SQL statement; add --json for machine-readable output, or --file x.sql
npx wrangler d1 export jbd-cloud --remote --output backup.sqlExports schema and data
npx wrangler d1 time-travel restore jbd-cloud --timestamp …Restores the database to a past moment (7 days on Free)
npx wrangler d1 delete jbd-cloudDeletes a database (irreversible)

Secrets

CommandWhat it does
npx wrangler secret put NAME --env productionPrompts for a value (hidden) and stores it; also reads from standard input: printf '%s' "$V" | npx wrangler secret put NAME --env production
npx wrangler secret list --env productionShows secret names (never values)
npx wrangler secret delete NAME --env productionRemoves a secret

Deploying

CommandWhat it does
npx wrangler deploy --env production --dry-run --outdir .wrangler/dryBundles and validates without uploading; shows size and bindings
npx wrangler deploy --env productionUploads code and assets, creates a new version, applies triggers
npx wrangler deployments list --env productionRecent deployments
npx wrangler versions list --env productionAll versions with ids
npx wrangler rollback --env productionMakes the previous version live again (you may pass a version id)
npx wrangler delete --env productionDeletes the Worker and its triggers

Observing

CommandWhat it does
npx wrangler tail --env productionLive log stream: each request, each cron run, every console.log
… --format pretty / --format jsonReadable or machine output
… --status errorOnly failed invocations

This repo's npm shortcuts (in cloud/)

npm run build              # compile the shared frontend and assemble dist-assets
npm run db:migrate:local   # local migrations
npm run dev                # build + migrate + wrangler dev
npm run vapid              # print new production keys
npm run deploy:dry         # build + dry-run deploy
npm run deploy             # build + remote migrations + deploy
