Feature tour

What the app does for the people who use it, screen by screen. Knowing the features first makes the code much easier to follow.

⏱ 10 min readGuide 4 of 47

The header

Every screen shares one header: the brand (link home), the Epics / For You switch, an issue box (Epics only), the JARVIS indicator, refresh, theme switcher and settings. On phones the header wraps into two rows.

The Epics view

Track any issue (usually an epic). The app collects every bug that is linked to it (any link type: blocks, relates to…) or is its child, using this JQL:

(issue in linkedIssues("ABC-123") OR parent = "ABC-123") AND issuetype in ("Bug") ORDER BY created DESC
  • Tabs: several tracked issues at once, each with its own filters and stars.
  • Header card: the epic's key, status, title and a progress bar (closed / total).
  • KPI tiles: total, open, closed, open more than N days, stale, unassigned, new/changed, average open age, oldest open. Clicking a tile filters the table.
  • Charts: status donut, severity, priority, open-by-assignee bars, a weekly flow chart (created vs resolved, with open backlog line) and an age histogram. Clicking a chart item toggles a filter.
  • Table: sortable columns, column picker, search (/), quick filters, "show more" paging, CSV export (with spreadsheet-formula protection).
  • Markers: ★ stars; NEW / UPDATED since you pressed "Mark all as seen"; STALE when not updated for N days; age coloured green / amber / red by thresholds you choose.

For You

Every bug assigned to you across all projects (open ones, plus closed ones touched in the last 90 days), regardless of epic.

  • Greeting and a one-line summary ("5 open bugs on your plate, 2 gone stale").
  • Nine KPIs: total, open, in progress, blocked, resolved/closed, newly assigned (7 days), updated (24 hours), stale, oldest unresolved.
  • Charts: status, open by project, priority, severity, age; lists of the oldest and the stalest bugs; the latest JARVIS events.
  • Blocked detection: a status named like Blocked / On hold, a blocked label, or an open "is blocked by" link.
  • Detail drawer: description, comments, change history, linked issues, and "Open in Jira". Rows show the latest activity JARVIS saw.

JARVIS

The assistant that watches your assigned bugs.

  • Detects new assignments, status changes, reopenings, resolutions, closings, comments, priority and severity changes, reassignments and other edits.
  • Announces them with a voice (browser speech) and desktop notifications, using witty templates: "Good evening, sir. A new bug has landed on your desk…".
  • Groups bursts: two events are spoken separately; three or more become one briefing. Repeats on one bug collapse ("3 new comments").
  • Respects you: your own actions are never announced; low-importance edits are never spoken; quiet hours; "important only" or "digest" modes; per-event-type switches.
  • Control panel: status, last and next check, pause, check now, test announcement, simulate events, history with read/unread, settings (voice, speed, volume, how to address you).
  • Cloud extras: background notifications via Web Push even when the browser is closed; checks run every 5 minutes on Cloudflare.

The engine is explained in JARVIS: how changes are detected and JARVIS: speech and notifications.

Settings and data

  • Connection: Local edition: Jira URL, email, API token (verified before saving). Cloud: signed-in account, Jira site picker, advanced fields, sign out, disconnect, delete account. Demo: a note explaining sample data.
  • Appearance: theme and five accent colours.
  • Markers and refresh: warn / critical / stale thresholds in days, auto-refresh interval.
  • Data on this device: clear everything stored in this browser.

Small things that matter

  • Mobile layout: tables turn into cards, filters into a bottom sheet.
  • Keyboard: / search, r refresh, Esc closes drawers.
  • Accessibility: real buttons, ARIA labels, visible focus, reduced-motion support.
  • Offline tolerance: the last result is cached and shown if Jira is unreachable.
  • The "Get the app" dialog with install steps and a ready-made prompt for AI assistants (hosted demo and Local).
