Glossary: every term in plain words

Each word is explained first simply, then precisely, with where it appears in this app. Use your browser's find (Ctrl/⌘ + F) to jump to a term.

A to C

API (Application Programming Interface)
A menu for programs. A website has pages for people; an API has "endpoints" for programs. Jira's API lets a program ask "give me issue ABC-123" and get data back as JSON instead of a web page. This app calls Jira's REST API, and itself offers an API (/api/...) to its own page. See API reference.
Access token
A temporary key that proves "this request is allowed to act as this person". Atlassian's access tokens expire after about an hour. Sent in the Authorization: Bearer … header.
AES-GCM
A way to lock data so only someone with the key can read it, and to detect if anyone tampered with it. The Cloud edition stores Atlassian tokens encrypted with AES-256-GCM. See The cryptography, simply.
ADF (Atlassian Document Format)
Jira stores rich text (descriptions, comments) as a JSON tree, not plain text. The app's adfToText function flattens it into readable text.
Asset (static asset)
A file that is sent to the browser as it is: HTML, CSS, JavaScript, images. On Cloudflare, static assets are served for free without running your code.
Atlassian
The company that makes Jira and Confluence. Its sign-in service (auth.atlassian.com) and API gateway (api.atlassian.com) are used by the Cloud edition.
Backend / frontend
The frontend is what runs in your browser (the page, buttons, charts). The backend is what runs on a server (talking to Jira, storing data). In this app the frontend is in src/client and public; the backends are src/server (Local) and cloud/src (Cloud).
Baseline
JARVIS's first look at your bugs. It records what exists without announcing anything, so you are not flooded with old history. Later checks compare against it.
Binding
A Cloudflare term: a named connection from your Worker's code to a resource. env.DB is the binding to the D1 database; env.ASSETS to the static files.
Browser storage (localStorage)
A small notebook each website gets inside your browser. The app keeps preferences, filters and cached results there. Never tokens.
Budget (subrequest budget)
The app's own counter of outgoing calls during one Worker run, because Cloudflare's free plan allows only 50 per run. See The free tier.
Callback URL (redirect URI)
The address Atlassian sends the user back to after they agree to give access. For this app: …/auth/callback. It must match exactly what is registered in the Atlassian developer console.
Changelog
Jira's history of an issue: who changed which field, from what, to what, when. JARVIS reads it to know exactly what happened.
Cloud ID
Atlassian's internal id for a Jira site. OAuth requests go to api.atlassian.com/ex/jira/{cloudId}/… instead of the site's own address.
Cookie
A small value a website asks your browser to keep and send back on every request to that site. The Cloud edition's session cookie __Host-jbd_sid is how it knows you are signed in. See HTTP, cookies and CORS.
CORS (Cross-Origin Resource Sharing)
A browser safety rule: a page from site A cannot read responses from site B unless site B says it is OK. Jira does not allow this for its API, which is why every edition needs a server in the middle.
Cron / Cron Trigger
An alarm clock for programs. * * * * * means "every minute". Cloudflare runs the Worker's scheduled() function on that schedule.
CSP (Content Security Policy)
A list the server gives the browser saying "only run scripts from here, only connect to there". It blocks many attacks even if something malicious sneaks into the page.
CSRF (Cross-Site Request Forgery)
A trick where a bad website makes your browser send a request to a good website you are signed in to. Defended by checking the Origin header and a custom X-JBD header. See Threat model.

D to L

D1
Cloudflare's database, based on SQLite. Data is stored in tables (rows and columns) and read with SQL. The Cloud edition's database is named jbd-cloud.
Data centre / edge
A building full of servers. Cloudflare has hundreds around the world; "the edge" means "the one closest to you". Your request is handled near you, which is fast.
Deploy
Copying your code to where it runs for real users. wrangler deploy uploads the Worker and its assets to Cloudflare.
ECDH / ECDSA
Two kinds of elliptic-curve cryptography. ECDSA makes digital signatures (used to sign the VAPID token for push). ECDH lets two parties agree a shared secret over a public channel (used to encrypt push messages).
Edition
One of the three ways this app runs: Local, Cloud, Demo. See Editions.
Endpoint
One address of an API, such as GET /api/mine.
Environment (dev / production)
Separate copies of the same app with different settings. dev runs on your computer with a fake Atlassian; production is the real one on the internet.
Epic
A big Jira issue that groups smaller ones. The Epics view shows every bug linked to or under an epic.
Event (JARVIS event)
One meaningful thing that happened to one of your bugs: assigned, status, reopened, resolved, closed, comment, priority, severity, reassigned away, unassigned, updated.
Grant
The permission a user gives an app on Atlassian's consent screen. Stored as tokens.
Hash (SHA-256)
A one-way fingerprint of data. Easy to compute, impossible to reverse. The database stores only a hash of your session cookie, so a database leak does not leak sessions.
HKDF
A recipe for turning one secret into several strong keys. Used inside Web Push encryption.
HLD / LLD
High-level design (the big boxes and how they connect) and low-level design (the inside of each box: modules, tables, functions).
HTTP / HTTPS
The language browsers and servers speak. HTTPS is HTTP inside an encrypted tunnel. Requests have a method (GET, POST), a path, headers and sometimes a body; responses have a status code (200 OK, 404 Not Found…).
HttpOnly / Secure / SameSite
Cookie safety flags. HttpOnly: page scripts cannot read it. Secure: only sent over HTTPS. SameSite=Lax: not sent on most cross-site requests.
IDOR (Insecure Direct Object Reference)
A bug where changing an id in a request shows someone else's data. Prevented by always filtering by the signed-in user.
Isolate
How Cloudflare runs your Worker: a tiny, separate JavaScript sandbox that starts in milliseconds. Many isolates share one machine safely.
JQL (Jira Query Language)
Jira's search language, like assignee = currentUser() AND issuetype = Bug. See How Jira's REST API works.
JSON
A text format for data: {"key": "ABC-1", "status": "Open"}. Almost all APIs speak it.
JWT (JSON Web Token)
A signed, compact token: header.payload.signature. The VAPID token for Web Push is a JWT.
Lease
A short, self-expiring lock. Before refreshing a token, the Worker takes a 30-second lease so two parallel requests do not both refresh.

M to R

Migration
A numbered SQL file that changes the database structure (0001_init.sql, 0002_…). D1 remembers which ones ran, so each runs exactly once.
Mock
A fake version of a real service, used in tests. mock-atlassian.mjs pretends to be Atlassian, Jira and a push service.
Node.js
A program that runs JavaScript outside the browser. The Local edition's server runs on Node.js.
OAuth 2.0 (3LO)
A standard way for a user to let an app act on their behalf without giving the app their password. "3LO" (three-legged OAuth) means three parties: the user, the app, and Atlassian. See Signing in with Atlassian.
Origin
The scheme + host + port of a URL: https://jira-bug-dashboard-cloud.shouryacode2021.workers.dev. The browser's security rules are built around origins.
Pagination
Getting a long list in pages (for example 100 issues at a time) using a "next page" token.
Personal Data Reporting API
An Atlassian API that apps storing personal data must call regularly, so Atlassian can say "this account was closed, erase it". See Privacy and the data life cycle.
Polling
Asking repeatedly "anything new?". JARVIS polls Jira on a schedule because Jira cannot push changes to a private app easily.
Push service / Web Push
A service run by the browser maker (Google, Mozilla, Apple, Microsoft) that delivers messages to a browser even when no tab is open. See Service workers and Web Push.
Rate limit
A cap on how many requests are allowed in a time window. Jira, Atlassian and Cloudflare all have them; the app has its own too.
Refresh token / rotation
A long-lived key used only to get new access tokens. Atlassian rotates it: each use returns a new one and disables the old. See Refreshing and rotating tokens.
REST
A common style of HTTP API: things are "resources" at URLs (/rest/api/3/issue/ABC-1), and methods say what to do with them.
Route
One path the server answers (GET /api/mine), or, in Cloudflare, a URL pattern a Worker runs on.

S to Z

Scope
One specific permission requested from Atlassian: read:jira-work, read:jira-user, read:me, offline_access. The app asks only for read scopes.
Secret (Worker secret)
A setting whose value is hidden: stored encrypted by Cloudflare, available to the Worker, never shown again. Examples: TOKEN_ENC_KEY, ATLASSIAN_CLIENT_SECRET.
Server-Sent Events (SSE)
A long-lived HTTP response where the server keeps sending small messages. The Local edition streams JARVIS events to the page this way.
Service worker
A small script a website installs in the browser that can run in the background, for example to receive push messages. File: cloud/public/sw.js.
Session
"You are signed in" remembered between requests, via a cookie. Expires after 30 days, or 7 days without use.
Snapshot
JARVIS's saved list of your bugs and when each was last updated. New results are compared against it.
SQL
The language for databases: SELECT name FROM users WHERE id = ?.
SSRF (Server-Side Request Forgery)
Tricking a server into calling an address it should not (for example internal cloud metadata). Push endpoints are checked against an allow-list to prevent it.
Status category
Jira groups every status (whatever its name) into three categories: new (to do), indeterminate (in progress), done. JARVIS uses this to tell "reopened" from "moved".
TypeScript
JavaScript with types. All the app's code is TypeScript, compiled to JavaScript by tsc (or bundled by Wrangler for the Worker).
VAPID
A way for a server to prove to push services who it is, using a signed JWT and a public key. Keys are generated by gen-vapid.mjs.
Worker (Cloudflare Worker)
Your code running on Cloudflare's network. It wakes up for each request (or each cron tick), does its work in milliseconds, and goes back to sleep. See Workers.
Wrangler
Cloudflare's command-line tool for Workers: run locally, create databases, set secrets, deploy, read logs. See Wrangler cheat sheet.
workers.dev
A free web address Cloudflare gives every account: <worker>.<subdomain>.workers.dev.
