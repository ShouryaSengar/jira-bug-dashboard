What Cloudflare is and how the edge works

Cloudflare runs one of the world's largest networks of data centres. Websites put Cloudflare in front of them for speed and protection, and developers run code on it. Here is what that means, from zero.

⏱ 9 min readGuide 28 of 47

The internet in one paragraph

Your computer and a website's computer (a server) talk by sending small packets across many networks. Distance matters: a packet from Mumbai to a server in Virginia and back takes about 200 milliseconds just travelling. A page that needs ten round trips takes two seconds before any work is done.

What Cloudflare adds

Explained simplyInstead of one shop in a faraway city, imagine a chain with a branch in every neighbourhood. You walk to the nearest one. Small things (bread, milk = static files) are on the shelf there. For special orders, the local branch can cook it on the spot (run your code), and it has a pantry (database) it can reach.
  • The edge: hundreds of data centres in cities around the world. Your request goes to the nearest one, chosen automatically by a routing technique called Anycast (many locations share the same IP address).
  • CDN (content delivery network): static files are kept close to users.
  • Protection: DDoS mitigation, TLS (the padlock), firewall rules.
  • Developer platform: Workers (your code), D1 (database), KV, R2 (file storage), Queues, Durable Objects, cron triggers, and more.

Your account, organised

  • Account: everything belongs to an account (yours has an account id like 87d5ce15…).
  • Workers & Pages: each Worker has a name, versions (every deploy is a version), triggers (routes, cron), settings (variables, secrets, bindings) and metrics.
  • D1: each database has a name, an id, a region and a console where you can run SQL.
  • Zones (domains): only needed if you use your own domain name. With workers.dev you do not need one.

Why Cloudflare for this project

  • Free tier that never sleeps: other free hosts pause idle apps, which would stop background monitoring.
  • Cron included: no separate scheduler service.
  • A database included: D1, with free daily allowances.
  • Global and fast: the page is served from the data centre nearest each user.
  • One tool: Wrangler does local development, databases, secrets, deploys and logs.
